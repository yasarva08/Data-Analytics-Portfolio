# Major Data Analytics Project

This repository contains my **major end-to-end data analytics project** developed as part of my learning journey in data analytics.

The project demonstrates how raw business data can be transformed into meaningful insights using multiple analytics tools including **Python, SQL, Excel, and Power BI**.

---

## Project Included

### Retail Profit Leakage Analysis

The **Retail Profit Leakage Analysis** project investigates how profit is affected by factors such as discount strategies, product categories, regional performance, and customer purchasing behavior.

The objective is to identify areas where businesses lose profit and provide insights that can help improve pricing strategies and business decision-making.

---

## Tools & Technologies Used

The analysis was performed using the following tools:

* **Python** – Data cleaning, feature engineering, and exploratory data analysis
* **SQL** – Business queries and profitability analysis
* **Microsoft Excel** – Pivot-based analysis and business dashboards
* **Power BI** – Interactive executive dashboard and data visualization

---

## Project Objective

The main goal of this project is to:

* Identify **profit leakage sources** in retail sales data
* Analyze the impact of **discount strategies on profitability**
* Evaluate **regional and category-level performance**
* Understand **customer purchasing patterns**
* Build **interactive dashboards for business insights**
