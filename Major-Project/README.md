# Major Data Analytics Project

This repository contains my major data analytics project completed as part of my journey.

## Project Included

### Retail Profit Leakage Analysis

This project focuses on identifying profit leakage in a retail dataset and analyzing the impact of discount strategies on overall profitability.

The analysis is performed using multiple tools and technologies:

* **Python** for data cleaning and exploratory data analysis (EDA)
* **SQL** for data querying and analytical insights
* **Excel** for business analysis and pivot-based insights
* **Power BI** for building an interactive dashboard

## Project Objective

The objective of this project is to analyze retail sales data and identify areas where profit is being lost due to factors such as excessive discounting, regional performance differences, and product category behavior.

## Tools & Technologies

* Python (Pandas, NumPy, Matplotlib, Seaborn)
* SQL
* Microsoft Excel
* Power BI
