# Data Cleaning & Preparation

This folder contains the Python script used for cleaning and preparing the retail dataset before performing analysis.

## Tasks Performed

* Loading the dataset
* Checking dataset structure
* Identifying missing values
* Checking duplicate records
* Converting date columns
* Creating new features:

  * Profit Margin
  * Loss Flag
  * Year
  * Month

The cleaned dataset generated from this process is used for further analysis in SQL, Excel, and Power BI.
