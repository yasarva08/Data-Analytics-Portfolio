# 🛒 Retail Sales Analysis using SQL

## 📌 Project Overview
This project focuses on analyzing retail sales data using SQL to uncover meaningful business insights.  
It includes data cleaning, exploration, and advanced queries to understand customer behavior, sales performance, and trends.

---

## 🎯 Objective
The goal of this project is to:
- Analyze sales data to identify trends and patterns  
- Understand customer purchasing behavior  
- Evaluate category-wise performance  
- Generate insights to support business decision-making  

---

## 🛠️ Tools & Technologies
- SQL (PostgreSQL)
- Dataset: Retail Sales Data

---

## 📊 Key Analysis Performed

### 🔹 Data Cleaning
- Removed null and inconsistent records  
- Ensured data quality for accurate analysis  

### 🔹 Data Exploration
- Total number of sales transactions  
- Unique customers and categories  

### 🔹 Business Analysis
- Sales by category  
- Customer segmentation  
- Gender-wise category preference  
- Time-based sales analysis (Morning / Afternoon / Evening)  
- Monthly sales trends  
- Average order value  
- Top 5 customers by total spending  

---

## 🔍 Key Insights
- Identified top customers contributing the highest revenue  
- Found peak sales time periods  
- Analyzed monthly trends for better forecasting  
- Observed category-wise and gender-based purchasing behavior
