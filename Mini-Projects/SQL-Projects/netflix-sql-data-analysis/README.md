# Netflix SQL Data Analysis

## Project Overview

This project analyzes the **Netflix Movies and TV Shows dataset** using SQL to answer business questions and extract insights.

The goal of this project is to explore Netflix content trends such as:

- Distribution of Movies vs TV Shows
- Most common ratings
- Content by country
- Genre distribution
- Actor and director insights

This project demonstrates the use of **SQL for data analysis and business problem solving**, which is an essential skill for Data Analyst roles.

---

## Dataset

The dataset contains information about Netflix content including:

- Title
- Type (Movie / TV Show)
- Director
- Cast
- Country
- Release Year
- Rating
- Duration
- Genre
- Description

Dataset Source: Kaggle – Netflix Movies and TV Shows

---

## Tools Used

- SQL
- PostgreSQL
- Kaggle Dataset

---

## Business Questions Solved

1. Count the number of Movies vs TV Shows.
2. Find the most common rating for Movies and TV Shows.
3. List all movies released in a specific year.
4. Identify the top 5 countries with the most content.
5. Find the longest movie.
6. Find content added in the last 5 years.
7. Find content by a specific director.
8. Identify TV Shows with more than 5 seasons.
9. Count content items by genre.
10. Analyze content releases in India by year.
11. List all documentary movies.
12. Find content without a director.
13. Count movies featuring a specific actor in the last 10 years.
14. Find the top actors appearing in Indian movies.
15. Categorize content based on keywords like **Kill** or **Violence**.
