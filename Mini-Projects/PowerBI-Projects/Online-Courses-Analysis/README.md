# 📊 Online Courses Analysis Dashboard

## 🔍 Project Overview

This project focuses on analyzing an online courses dataset to understand learner engagement, course performance, and platform trends.
The goal was to extract meaningful insights that can help improve course accessibility, content strategy, and user engagement.

The analysis was performed using Python for data exploration and Power BI for building an interactive dashboard.

---

## 🎯 Problem Statement

Online learning platforms host thousands of courses, but understanding what drives engagement is critical.

This project aims to answer:

* Which course categories perform best?
* How language impacts reach and accessibility
* Whether course duration affects engagement
* The role of subtitles in increasing viewership
* How instructor ratings influence course popularity

---

## 🛠️ Tools & Technologies Used

* **Power BI** – Dashboard creation & visualization
* **Python (Pandas, Matplotlib, Seaborn)** – Data analysis
* **CSV Dataset** – Online courses data

## 📈 Key Insights

* 📌 **Data Science** emerged as the top-performing category in terms of average viewership
* 🌍 **English dominates** the platform with the majority of course content
* 🎯 **Short courses** tend to attract more enrollments compared to longer programs
* 🌐 Courses with **multiple subtitles** show higher engagement, highlighting the importance of accessibility
* ⏱️ **Moderate duration courses** perform better than extremely short or long ones
* ⭐ Highly rated instructors tend to attract more learners and build trust

---

## 💡 Business Recommendations

* Expand courses in multiple languages to increase global reach
* Focus more on high-demand domains like Data Science and IT
* Improve subtitle availability for better accessibility
* Promote top-rated instructors to boost credibility
* Optimize course duration to balance depth and retention
