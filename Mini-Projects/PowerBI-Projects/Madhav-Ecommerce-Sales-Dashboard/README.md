# 📊 Madhav Ecommerce Sales Dashboard (Power BI)

## 🚀 Project Overview

This project analyzes the sales performance of Madhav Store across India using Power BI.
The dashboard helps track revenue, profit trends, customer behavior, and payment insights.

---

## 🎯 Objective

To build an interactive dashboard that provides insights into:

* Sales performance
* Profit trends
* Customer purchasing patterns
* Payment mode distribution

---

## 🛠️ Tools & Technologies

* Power BI
* Excel / CSV
* Data Visualization

---

## 📌 Key Insights

* 📈 Highest profit observed in specific months (strong seasonal trend)
* 💰 COD is the most used payment method (~44%)
* 🛍️ Clothing category contributes the highest share (~48%)
* 📉 Some months show negative profit (loss detection)
* 🏆 Top customers contribute significant revenue

---

## 📊 Dashboard Features

* KPI Cards (Amount, Quantity, Profit, AOV)
* Profit by Month (Bar Chart)
* Category-wise Analysis
* Payment Mode Distribution
* Customer-wise Sales
* Interactive Filters (Quarter, Category)
